# Story log

Continuity across weeks: one entry per week, newest last. The story editor reads all of it before proposing angles and appends to it at the end of every `/marathon-week` run; the analyst adds last week's stats the next Sunday.

Entry format:

```
## <YYYY-Www> — <title of the video>
- Story: one line
- Numbers: the week's headline numbers
- Callbacks used / threads opened: e.g. "first time running in rain" (open), "calf pain" (closed)
- Posted: IG <link>, TikTok <link>, YT <link>   (owner pastes)
- Stats after 7 days: views / likes / comments / shares / follows per platform   (owner pastes)
- What worked / what didn't: one line each
```
