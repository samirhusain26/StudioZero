## Free scheduler comparison

Buffer Free permits **three channels total, ten queued posts per channel**, with queue slots refilling as posts publish. It does not cover six accounts. Current desired allocation is X + Instagram + YouTube; Facebook and Threads would need direct eligible APIs. No duplicate Buffer account workaround is proposed.

Buffer API Free currently allows **one API key, one OAuth client, 100 calls/15 minutes, 250/day and 3,000/30 days**. This implementation caps itself at 80/15 minutes, 200/day and 2,400/30 days. All calls, including reconciliation and errors, count locally. API analytics are experimental; no dependable conversion reporting is assumed. Media must be publicly accessible because native API uploads are not available.

The Pi holds a seven-day queue locally and requests automatic `shareNow` publishing at the scheduled time. It does not rely on Buffer's existing legacy afternoon schedule. Changing that legacy schedule has not been authorized/applied. An accepted API request or Buffer `sent` label is insufficient launch evidence: verify remote permalink and public visibility.
