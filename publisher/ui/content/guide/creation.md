# Creation workspace

Studio shows each project once. Open a project to start a brief or resume its saved videos. Optional details stay collapsed; **Use example** supplies a starting point.

Save a brief, then copy the prompt to repo-enabled ChatGPT or Claude Code. Plain chat can draft text but cannot run this repository. Copying does not start a job: the workspace waits for files.

Return the generated `manifest.json` and every file it lists. The manifest must identify this production, project and revision and include exact filenames, sizes, SHA-256 hashes and media types. Studio checks them before replacing the current cut. A failed return leaves the previous cut intact. Revision requests retain feedback and target the existing production.

Watch the actual cuts before approving their revision. This local decision does not finalize a batch, approve its exact publishing text or schedule anything. Scalargame publishing still uses the finalized batch importer and its separate approvals. Browser preview/export remains available from the Scalargame project.

Explainers starts with a topic and a research decision; a hold stops cut admission. Accepting research here does not approve the project's script, voice, visuals or final delivery gates. Marathon delivery is manual and private. Originals remains on hold; no paid run starts from the creation workspace.
